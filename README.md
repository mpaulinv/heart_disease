# Heart Disease Prediction Project

This repository contains a complete end-to-end data science project focused on analyzing the Cleveland Heart Disease dataset. The project includes data exploration, preprocessing, feature engineering, model training, evaluation, and interpretation.

## Project Overview

The objective of this project is to:
1. Analyze the dataset and identify the main factors associated with heart disease.
2. Build predictive models to evaluate the contributing factors.
3. Discuss the results and provide insights into the relationships between variables.

## Dataset

The dataset used in this project is the **Cleveland Heart Disease dataset**, which is publicly available at the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/45/heart+disease). The dataset contains 303 observations and 14 variables, including demographic, clinical, and diagnostic information.

## Key Features

- **Data Exploration**: Descriptive and exploratory analysis of categorical and continuous variables.
- **Feature Engineering**: Creation of interaction terms, transformations, and dummy variables.
- **Modeling**: Logistic regression and Random Forest models with hyperparameter tuning.
- **Evaluation**: Metrics such as accuracy, precision, recall, F1-score, and AUC.
- **Interpretation**: Coefficient interpretation and feature importance analysis.
